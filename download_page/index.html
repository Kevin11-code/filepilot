Enterprise-Grade Security

FilePilot goes beyond standard SFTP clients with advanced security measures designed to protect your most sensitive data.

  • SecureString Implementation Passwords encrypted in memory with XOR encryption and random keys
  • Memory Protection Automatic memory clearing and overwriting with random data
  • Credential Storage System keyring integration with optional configuration encryption
  • Zero Exposure Stdin password input prevents command-line credential exposure

Quick Installation

1. Download filepilot.exe
2. Double-click to run the executable
3. No installation required - runs directly
4. Optional: Add to PATH for command-line access
# Make executable and run
chmod +x filepilot
./filepilot

# Or install globally
sudo mv filepilot /usr/local/bin/filepilot
filepilot

System Requirements

Windows

  • Windows 10 (1903+) or Windows 11
  • 64-bit architecture required
  • 4 GB RAM minimum, 8 GB recommended
  • 100 MB available disk space
  • Visual C++ Redistributable (auto-installed)

Linux

  • Ubuntu 20.04+, Debian 11+
  • RHEL 8+, CentOS 8+, Rocky Linux 8+
  • SUSE Linux Enterprise 15+, openSUSE Leap 15+
  • Fedora 35+, Arch Linux
  • 4 GB RAM minimum
  • 100 MB disk space
  • Python 3.8+ (usually pre-installed)

macOS

  • macOS 11.0+ (Big Sur or later)
  • Intel x64 & Apple Silicon (M1/M2/M3) support
  • 4 GB RAM minimum, 8 GB recommended
  • 100 MB available disk space
  • Native Keychain integration
